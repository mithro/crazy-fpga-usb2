# P1 result: `hello` applet on NeTV2 hardware (2026-09-06)

First closed loop of build → JTAG load → UART observation. Design:
`usb2soft/applets/hello.py` (PLL 50→60 MHz, DNA reader, heartbeat LEDs, banner
on the UART at 115200 8N1 once per second). Toolchain: Vivado 2025.2 via
amaranth 0.5.9's `XilinxPlatform(toolchain="Vivado")`.

The banner repeated six times in the 6 s capture window, i.e. the 1 Hz timer
from the 60 MHz PLL output is correct, and the DNA read is stable across
lines. The DNA `0742C4E63B9085C` is now the identity of the rpi5-netv2 board
(57 bits, MSB first).

## Problems met and fixed

- OpenOCD `linuxgpiod` failed with `Error requesting gpio line tdo`: the
  five JTAG lines were still exported through `/sys/class/gpio` by an earlier
  sysfsgpio-based flow. On a Pi 5 the sysfs numbers are `571 + BCM line`
  (RP1 controller base), so the release step in `host/netv2_run.py` computes
  the base from the 54-line header controller before unexporting.
- `w -h` shows our own non-interactive ssh as `sshd-session: tim [priv]` and
  the desktop as a `lightdm` session; both are now ignored by the "someone
  else is logged in" check.
